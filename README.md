# Self Intro

A tiny single-page self introduction built with plain HTML and inline CSS. No dependencies.

## Usage

Open `index.html` in a browser, or serve it locally:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000

## Customize

Edit `index.html`:

- `<title>` and `<h1>` — your name (and the avatar initial)
- `.role` — your title
- `p.bio` — your intro text
- `.links` hrefs — your real URLs
